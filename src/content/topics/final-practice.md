Like month 6, there is no new theory. Each session has **4–5 problems** from easy to hard, taken from well-known national and international contests.

Suggested routine:

1. Simulate a real contest: 3–5 hours, no editorials.
2. Write down which technique each problem used and why you did or didn't see it.
3. Keep a personal **template file** with every data structure from this roadmap, tested.
4. Upsolve, then participate in live Codeforces / AtCoder rounds weekly.
