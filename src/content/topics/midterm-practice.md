This month is all practice. Each session: **4–5 problems** from real contests, solved under time pressure.

How to practice well:

1. Set a timer (about 2 hours per set).
2. Don't read the tag: identifying the technique is part of the skill.
3. If stuck after ~30 minutes, read only the first hint of the editorial.
4. **Upsolve** every problem you couldn't finish, then re-implement it from scratch a few days later.
